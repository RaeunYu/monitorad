# 지표는 프로토콜과 내장 레지스트리로 추상화한다

Status: accepted

HUD로 표시할 수 있는 조작 지표를 나중에 간단한 코딩으로 추가하려면 지표마다 관측·현재 값·글리프·HUD/메뉴바 표현을 캡슐화해야 한다. 우리는 `AdjustableMetric` 프로토콜과 내장 레지스트리를 쓰고, 새 지표는 구현체 하나와 등록 한 줄로 추가한다. 동적 플러그인 로딩은 서명·샌드박스·ABI 안정성 비용 때문에 v1에서 제외한다.

## Considered Options

- 플러그인 번들 로딩: 외부 확장은 가능하지만 배포·서명·API 안정성 부담이 크다.
- 볼륨/밝기 하드코딩 후 리팩터: 첫 PR은 빠르지만 세 번째 지표에서 구조를 갈아엎게 된다.

## Consequences

- Core 모듈은 AppKit 의존 없이 단위 테스트할 수 있다.
- 비조작 지표(배터리)는 같은 프로토콜에 얹지 않고 별도 표시 계층으로 둔다.
