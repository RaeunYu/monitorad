# 메뉴바 인디케이터는 항목 하나에 최대 3지표를 담는다

Status: accepted

Tahoe 메뉴바 높이는 22pt이고 항목 폭은 ControlCenter가 관리한다. 2×2 미니 링은 8~9pt로 줄어 판독이 불가능하고 4개를 한 줄로 늘어놓으면 메뉴바를 과점한다. 우리는 항목 하나에 최대 3개 지표를 표시하고, 1개면 큰 링(약 20pt), 2~3개면 작은 링을 나란히 배치한다. 4번째 지표는 선택할 수 없고(체크 비활성), 최소 1개는 항상 표시한다. 표시 순서는 팝오버에서 드래그로 정한다.

## Considered Options

- 정사각 고정 슬롯 모델(1칸/2칸/2×2): 22pt 높이에서 2×2가 비현실적이고 폭 모델이 비단조적이다.
- 4개 이상 허용: 메뉴바를 과점하고 판독성이 떨어진다.

## Consequences

- 항목이 화면 밖으로 밀리는 Tahoe 레이아웃 이슈에 대비해 추가 후 프레임 검사·재추가 방어 로직을 둔다.
