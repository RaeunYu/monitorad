# Quality: Definition of Done

## Definition of Done

- [ ] 이슈 브리프의 수용 기준을 모두 충족
- [ ] 테스트 추가·갱신 + 실행 명령과 결과를 PR 본문에 기록
- [ ] 최신 커밋 기준 `Verdict: APPROVE`
- [ ] 관련 문서 갱신(정책·도메인 용어·README)
- [ ] CI 도입 후: 필수 상태 체크 그린

## 테스트

- 코드 변경에는 테스트가 필요하다. 테스트가 불가능한 변경(문서·설정)이면 PR에 사유를 적는다.
- `implementer`가 로컬 테스트를 실행해 결과를 남기고, `verifier`가 같은 시나리오를 독립적으로 재실행한다.
- 테스트는 구현 세부가 아니라 행동을 검증한다. 실패 케이스와 엣지 케이스를 포함한다.

## CI

- 스택 확정 전: 로컬 테스트가 기준이다.
- 스택 확정 후: GitHub Actions CI를 도입하고 `main` ruleset에 필수 상태 체크를 추가한다.
- 실패 로그는 PR 코멘트가 아니라 CI 로그로 확인해 PR 히스토리를 가볍게 유지한다.

## 커밋·PR 위생

- Conventional Commits, squash 머지.
- 1 PR = 1 이슈(코드). PR 크기는 400줄/20파일 이하 권장.
- 비밀·토큰·`.env`는 커밋하지 않는다. `.gitignore`로 차단하고 발견 시 사용자에게 즉시 보고한다.
